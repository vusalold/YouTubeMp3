# 📱 About

YouTubeMp3 is a modern Android application built with **Kotlin** and **Jetpack Compose**.

It provides a beautiful Material 3 interface for downloading available audio content as MP3 while offering a premium download experience.

---

# ✨ Features

- 🎵 Download MP3 from supported YouTube links
- ⚡ Very fast download engine
- 📥 Smart Download Manager
- 📂 Download Queue
- 🔔 Smart Notifications
- 📋 Clipboard Detection
- 🖼️ Album Thumbnail Support
- 🏷️ Automatic Metadata & Cover Art
- 🎧 Multiple Audio Quality Options
- 🌙 Material 3 Dark UI
- 🔄 Auto Update System
- 📁 Download History
- 🚀 Built with Jetpack Compose
